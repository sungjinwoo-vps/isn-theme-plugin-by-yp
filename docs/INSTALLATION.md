# Installation Guide

1. In WordPress Admin, install `dist/infosecnexus-theme.zip` from Appearance > Themes > Add New > Upload Theme.
2. Activate the InfoSecNexus theme.
3. Install `dist/infosecnexus-toolkit.zip` from Plugins > Add New > Upload Plugin.
4. Activate InfoSecNexus Toolkit.
5. Install Elementor Free only from Plugins > Add New by searching the official WordPress repository.
6. Import `dist/infosecnexus-elementor-kit.zip` from Elementor import tools if desired.
7. Assign menus to Primary, Secondary, Footer, and Legal menu locations.
8. Review Appearance > Customize > InfoSecNexus Design.
