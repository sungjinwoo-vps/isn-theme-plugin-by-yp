# InfoSecNexus WordPress Theme Ecosystem

InfoSecNexus is an original cybersecurity newsroom theme ecosystem for WordPress.

It contains:

- `wp-content/themes/infosecnexus`: presentation theme with native WordPress fallbacks.
- `wp-content/plugins/infosecnexus-toolkit`: companion plugin for content blocks, conditions, Elementor widgets, search, newsletter, and optional modules.
- `elementor-kit`: importable Elementor starter kit source.
- `docker-compose.yml`: isolated local development stack for the iMac Docker host.
- `docs`: feature matrix, setup guides, and reports.
- `tools`: safe sync, bootstrap, test, and packaging scripts.

The project intentionally uses original names, code, assets, CSS, settings, and UI patterns.
