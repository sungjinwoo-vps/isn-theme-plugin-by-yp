# InfoSecNexus Elementor Kit

This kit source is a clean-room starter configuration for Elementor Free. It avoids Elementor Pro-only widgets and is designed to work with the InfoSecNexus theme and Toolkit widgets.

Import order:

1. Install and activate Elementor Free from the official WordPress.org repository.
2. Activate the InfoSecNexus theme and InfoSecNexus Toolkit plugin.
3. Import the kit ZIP from Elementor's Import/Export tools when available.
4. Reassign menus and inspect responsive breakpoints before publishing.
