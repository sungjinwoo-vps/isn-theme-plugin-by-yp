Original cybersecurity newsroom theme with Elementor-compatible theme locations and native WordPress fallbacks.

== Description ==

InfoSecNexus provides a responsive editorial design, Customizer design tokens, original header and footer builders, content blocks, newsletter capture, live search, native blog templates, Elementor theme locations, WooCommerce presentation support, and accessibility-focused frontend behavior.

== Installation ==

1. Upload and activate the theme.
2. Assign menus and review Appearance > Customize > InfoSecNexus Design.
3. Use Appearance > InfoSecNexus Features for built-in content blocks, search, newsletter, sidebars, Elementor widgets, and optional modules.
