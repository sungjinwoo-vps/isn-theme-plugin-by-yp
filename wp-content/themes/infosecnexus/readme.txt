Original cybersecurity newsroom theme with Elementor-compatible theme locations and native WordPress fallbacks.

== Description ==

InfoSecNexus provides a responsive editorial design, Customizer design tokens, original header and footer builders, native blog templates, Elementor theme locations, WooCommerce presentation support, and accessibility-focused frontend behavior.

== Installation ==

1. Upload and activate the theme.
2. Install the InfoSecNexus Toolkit plugin for content blocks, Elementor widgets, search, newsletter, and optional modules.
3. Assign menus and review Appearance > Customize > InfoSecNexus Design.
