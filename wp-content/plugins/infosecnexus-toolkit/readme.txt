Companion functionality for the InfoSecNexus WordPress theme.

== Description ==

InfoSecNexus Toolkit is now a legacy bridge. Current content blocks, conditional display rules, Elementor Free widgets, live search, newsletter capture, optional snippets, conditional sidebars, popups, featured videos, related posts, and WooCommerce presentation helpers are bundled directly into the InfoSecNexus theme.

== Installation ==

This plugin is no longer required for current InfoSecNexus theme installs. Update the InfoSecNexus theme, then deactivate and delete this legacy bridge when you are ready.
