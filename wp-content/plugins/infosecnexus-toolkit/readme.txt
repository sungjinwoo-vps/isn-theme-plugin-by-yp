Companion functionality for the InfoSecNexus WordPress theme.

== Description ==

InfoSecNexus Toolkit provides content blocks, conditional display rules, Elementor Free widgets, live search, newsletter capture, optional snippets, conditional sidebars, popups, featured videos, related posts, and WooCommerce presentation helpers for the InfoSecNexus theme.

== Installation ==

1. Install and activate the InfoSecNexus theme.
2. Upload and activate this plugin.
3. Configure modules from Settings > InfoSecNexus Toolkit.
